# Kagaz

AI-powered document workflow automation platform. Automatically classifies documents, extracts key information, validates it against organizational policy using RAG and LLMs, and routes documents for approval.

Built for **IT314 – Software Engineering**, following Agile (SCRUM).

## What it does
- User uploads the documents and selects the organization
- Classifies uploaded documents (invoice, contract, HR form, academic record, etc.)
- Extracts key fields from documents
- Validates extracted data against organizational policy (RAG-based)
- Summarizes documents
- Answers questions about documents via an AI chatbot
- Flags missing or inconsistent information
- Routes documents for approval automatically
